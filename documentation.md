# Техническое задание (ТЗ)

Проект: Площадка продажи новых и подержанных автомобилей
Версия: 1.1
Дата: 2025‑11‑01

---

## 1. Цель

Создать простой, бесплатный сайт для размещения объявлений о продаже новых и подержанных автомобилей в Северной Македонии. Пользователи могут самостоятельно добавлять, редактировать, приостанавливать и закрывать свои объявления.

## 2. Основные принципы

* Полностью бесплатный сервис, без оплат, подписок или платных опций.
* Два типа пользователей: **Физическое лицо (ФЛ)** и **Юридическое лицо (ЮЛ)**.
* ФЛ может иметь максимум **5 активных объявлений** одновременно.
* ЮЛ может иметь максимум **50 активных объявлений** одновременно.
* Объявления имеют три статуса: **Active**, **Paused**, **Closed**.
* Пользователь может закрыть объявление вручную.
* Объявления автоматически закрываются через **3 месяца** после последнего обновления.

## 3. Основные функции

### Каталог и поиск

* Поиск по основным параметрам: марка, модель, год, цена, город.
* Сортировка по дате, цене и году.
* Номерная пагинация.

### Карточка объявления

* Фото автомобиля (до 50 изображений).
* Базовые характеристики: год, объём двигателя, пробег, тип топлива, КПП, город.
* Контактные данные продавца.

### Публикация объявления

* Форма добавления объявления: Основные данные → Фото → Публикация.
* Проверка лимитов активных объявлений.
* Возможность поставить на паузу или закрыть объявление.
* Автоматическое закрытие после 3 месяцев неактивности (по полю `last_updated_at`).

### Избранное

* Добавление и удаление объявлений в избранное.
* У гостей хранится локально (localStorage), у авторизованных — на сервере.

### Админ‑панель

* Управление пользователями, объявлениями, модерацией и лимитами.
* Просмотр жалоб и управление статусами объявлений.

## 4. Архитектура

* **Frontend:** Next.js (SSR для SEO), React, TailwindCSS.
* **Backend:** Node.js (NestJS), REST API, PostgreSQL, Redis, S3‑совместимое хранилище.
* **Поиск:** PostgreSQL Full‑Text Search.
* **Мониторинг:** Sentry, базовые метрики.

## 5. API (пример)

```http
GET /api/listings?brand=Toyota&model=Corolla&year_gte=2018&price_lte=12000&city=Skopje&page=1
POST /api/listings                 # создать объявление
PATCH /api/listings/:id            # обновить
POST /api/listings/:id/publish     # активировать (с проверкой лимита)
POST /api/listings/:id/pause       # приостановить
POST /api/listings/:id/close       # закрыть
POST /api/favorites/:id            # добавить в избранное
DELETE /api/favorites/:id          # удалить из избранного
```

## 6. Схема данных (основное)

* **users(id, type enum('Individual','Business'), email, phone, created_at)**
* **listings(id, user_id, title, price, city, status enum('Active','Paused','Closed'), last_updated_at, created_at)**
* **vehicles(id, brand, model, year, engine_displ_l, mileage_km, fuel, transmission)**
* **favorites(id, user_id, listing_id, created_at)**

## 7. Поведение статусов

| Статус | Описание                                         |
| ------ | ------------------------------------------------ |
| Active | Объявление активно и отображается в каталоге     |
| Paused | Временно скрыто пользователем                    |
| Closed | Закрыто вручную или автоматически через 3 месяца |

## 8. Retention и автоматическое закрытие

* Автоматическое закрытие происходит через 90 дней после последнего обновления (`last_updated_at`).
* Фоновая задача (cron) проверяет объявления ежедневно и переводит их в статус `Closed`.
* Пользователь может вручную активировать, приостановить или закрыть объявление.

## 9. Регион и локализация

* Страна: Северная Македония.
* Валюта: MKD (доп. отображение в EUR возможно позднее).
* Язык интерфейса: македонский, русский (в MVP).

## 10. UI/UX

* Простая адаптивная структура.
* Главная страница содержит карточки с фото, ценой, годом и объёмом двигателя.
* Минимум кликов до контакта с продавцом.

## 11. План релиза

* **M1:** Каталог, карточка, публикация, лимиты, статусы, избранное.
* **M2:** Модерация, админ‑панель, авто‑закрытие, SEO.

## 12. Приёмочные критерии

* [ ] ФЛ не может иметь >5 активных объявлений.
* [ ] ЮЛ не может иметь >50 активных объявлений.
* [ ] Объявления переходят в `Closed` через 90 дней без обновления.
* [ ] Ручное закрытие работает корректно.
* [ ] Поиск и сортировка возвращают корректные данные.
* [ ] Избранное сохраняется и удаляется корректно.

---

**Версия 1.1 отражает:** отсутствие любых платежей, ручное и автоматическое закрытие объявлений, лимиты для типов пользователей, Северная Македония как основной регион.
