# Настройка SSH для деплоя

## Проблема: SSH недоступен (порт 22 закрыт)

Это типично для shared hosting - SSH часто нужно активировать вручную.

## Решение: Активировать SSH через cPanel

### Шаг 1: Проверить доступность SSH в cPanel

1. Войдите в cPanel: https://luna.mk-host.mk/cpanel
2. Найдите раздел **"SSH Access"**:
   - Может быть в секции **"Security"**
   - Или **"Advanced"**
   - Или **"Tools"**

### Шаг 2: Включить SSH доступ

Если SSH отключен:

1. В разделе **"SSH Access"** найдите кнопку:
   - **"Enable SSH Access"**
   - Или **"Manage SSH Access"**
   - Или **"Request SSH Access"**

2. Следуйте инструкциям:
   - Может потребоваться подтверждение по email
   - Может потребоваться указать причину использования SSH
   - Может быть автоматическая активация

### Шаг 3: Проверить настройки SSH

После активации проверьте:

1. **"SSH Access"** → **"Manage SSH Keys"**
2. Убедитесь, что ваш публичный ключ добавлен
3. Убедитесь, что ключ **авторизован** (кнопка "Authorize")

### Шаг 4: Добавить публичный ключ (если еще не добавлен)

На вашем Mac:

```bash
# Покажите публичный ключ
cat ~/.ssh/kupito_key.pub
```

Скопируйте весь вывод (начинается с `ssh-rsa ...`)

В cPanel:
1. **"SSH Access"** → **"Manage SSH Keys"** → **"Import Key"**
2. Вставьте публичный ключ
3. Имя: `kupito_key`
4. Нажмите **"Import"**
5. После импорта нажмите **"Authorize"**

### Шаг 5: Проверить подключение

```bash
ssh -i ~/.ssh/kupito_key kupitomk@luna.mk-host.mk
```

Если всё настроено правильно, вы должны подключиться.

---

## Альтернатива: Использовать другой порт

Некоторые хостинги используют нестандартный порт для SSH. Попробуйте:

```bash
# Порт 2222
ssh -i ~/.ssh/kupito_key -p 2222 kupitomk@luna.mk-host.mk

# Порт 2200
ssh -i ~/.ssh/kupito_key -p 2200 kupitomk@luna.mk-host.mk
```

---

## Если SSH недоступен на shared hosting

Некоторые shared hosting провайдеры не предоставляют SSH доступ. В этом случае:

1. **Обратитесь в поддержку mkhost.com:**
   - https://mkhost.com/en/other/contact
   - Запросите активацию SSH доступа
   - Укажите причину: "нужен для деплоя Node.js приложения"

2. **Проверьте тип тарифа:**
   - Некоторые тарифы не включают SSH
   - Может потребоваться обновление тарифа
