# Guides & Tutorials

Руководства для разработчиков по созданию, настройке и деплою платформ.

## 📄 Документы

### ⭐ [PLATFORM_CHECKLIST.md](./PLATFORM_CHECKLIST.md)
**Универсальный чеклист** для создания новой платформы.

**Используй это как главный гид!**

Содержит:
- Пошаговый чеклист (все этапы)
- Структура platform repository
- Конфигурация, переводы, ресурсы
- Environment variables
- Внешние сервисы
- Деплой и тестирование

### 📖 [PLATFORM_GUIDE.md](./PLATFORM_GUIDE.md)
Детальное руководство по созданию платформ.

Содержит:
- Best practices
- Примеры конфигурации
- Подробные инструкции
- Troubleshooting

---

### 🚀 [DEPLOYMENT.md](./DEPLOYMENT.md)
Инструкции по деплою на Render.com и другие платформы.

Содержит:
- Настройка PostgreSQL, Redis
- Настройка Backend и Frontend сервисов
- Environment variables
- CI/CD setup
- SSL и custom domains
- Мониторинг и логи

---

### 💻 [LOCAL_DEVELOPMENT.md](./LOCAL_DEVELOPMENT.md)
Настройка локального окружения для разработки.

Содержит:
- Установка зависимостей
- Настройка БД
- Запуск backend и frontend
- Hot reload
- Отладка

---

### ⚡ [QUICK_START_RU.md](./QUICK_START_RU.md)
Быстрый старт для тех, кто хочет сразу начать.

Содержит:
- Минимальные шаги для запуска
- Основные команды
- Быстрая настройка
