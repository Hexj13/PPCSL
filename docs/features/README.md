### 🚗 Фильтр популярных типов кузовов
**Реализовано** - Визуальный фильтр популярных типов кузовов на главной странице.

**Компонент:** `components/search-filters/PopularBodyTypesFilter.tsx`

**Функциональность:**
- 6 интерактивных плиток с изображениями типов кузовов (SUV, Hatchback, Wagon, Minivan, Sedan, Convertible)
- Двусторонняя синхронизация с дополнительными фильтрами
- Адаптивный дизайн: равномерное распределение на десктопе, горизонтальная прокрутка на мобильных
- Динамическое изменение title страницы при выборе типов кузовов
- Все 63 комбинации типов кузовов добавлены в sitemap для SEO
- Визуальная обратная связь: выделение выбранных плиток с маской и галочкой

**Интеграция:**
- Расположен в разделе "Основные фильтры" на главной странице
- Автоматическая синхронизация с `MultiSelectDropdown` в дополнительных фильтрах
- Поддержка URL параметров и восстановление из storage
