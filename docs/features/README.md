### 🚗 [VEHICLE_TYPE_TOGGLES.md](./VEHICLE_TYPE_TOGGLES.md)
Система переключения типа транспорта (легковой, грузовой, мотоцикл) для фильтрации объявлений на странице поиска и создания объявлений.

**Статус**: ✅ **ПОЛНОСТЬЮ РЕАЛИЗОВАНО** - Backend и Frontend готовы

**Основные возможности:**
- Переключатели типов транспорта в форме поиска (`SearchFilters`)
- Переключатели типов транспорта в форме создания объявления (`ListingForm`)
- Фильтрация марок и моделей по типу транспорта
- Фильтрация результатов поиска по типу транспорта
- Динамическое изменение типов кузова в зависимости от категории
- Условное скрытие полей (doors, drive_type для мото)
- Синхронизация с URL параметрами (`?vehicleType=car`)
- Классификация транспорта по категориям прав (B, C, A)

**Классификация:**
- 🚗 **Легковой** (`car`) - категория прав B: легковые авто, вэны, пикапы категории B
- 🚛 **Грузовой** (`truck`) - категория прав C+: грузовики, автобусы, трактора, спецтехника
- 🏍️ **Мототехника** (`moto`) - категория прав A: мотоциклы, скутеры, квадроциклы, снегоходы

**Содержит:**
- Полная архитектура системы
- Изменения в базе данных (поля `vehicle_types`, `vehicle_type`)
- Backend API с фильтрацией
- Frontend компоненты и интеграция
- Скрипты синхронизации и генерации данных
- Миграции БД для типов кузовов
- Примеры использования

### 🚗 Фильтр популярных типов кузовов
**Реализовано** - Визуальный фильтр популярных типов кузовов на главной странице.

**Компонент:** `components/search-filters/PopularBodyTypesFilter.tsx`

**Функциональность:**
- 6 интерактивных плиток с изображениями типов кузовов (SUV, Hatchback, Wagon, Minivan, Sedan, Convertible)
- Двусторонняя синхронизация с дополнительными фильтрами
- Адаптивный дизайн: равномерное распределение на десктопе, горизонтальная прокрутка на мобильных
- Динамическое изменение title страницы при выборе типов кузовов
- Все 63 комбинации типов кузовов добавлены в sitemap для SEO
- Визуальная обратная связь: выделение выбранных плиток с маской и галочкой

**Интеграция:**
- Расположен в разделе "Основные фильтры" на главной странице
- Автоматическая синхронизация с `MultiSelectDropdown` в дополнительных фильтрах
- Поддержка URL параметров и восстановление из storage
