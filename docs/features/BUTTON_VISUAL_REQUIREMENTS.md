# Требования к визуалу кнопок

Документ описывает визуальные требования и стандарты для всех кнопок в проекте PPCSL.

## Общие принципы

- Все кнопки должны быть доступными и соответствовать WCAG 2.1 AA
- Визуальная иерархия должна четко отражать важность действия
- Состояния кнопок должны быть визуально различимы
- Анимации и переходы должны быть плавными и не отвлекающими
- Кнопки должны быть консистентными во всем приложении

## Варианты кнопок

### Primary (Основная)

**Назначение:** Главное действие на странице или в секции.

**Визуальные характеристики:**
- **Фон:** `#40916B` (primary-500)
- **Текст:** Белый (`text-white`)
- **Высота (md/lg):** `52px` (фиксированная)
- **Тень (md/lg):** 
  - По умолчанию: `0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)`
  - При hover: `0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 10px 10px -5px rgba(0, 0, 0, 0.04)`
- **Тень (xs/sm):** Отсутствует
- **Hover:** 
  - Цвет текста: `primary-100` (светло-зеленый)
  - Тень увеличивается (только для md/lg)
- **Активное состояние:** Легкое затемнение фона
- **Граница:** Отсутствует
- **Скругление:** `rounded-lg` (8px)

**Использование:**
- Отправка форм
- Подтверждение важных действий
- Основные CTA (Call-to-Action)
- Навигация к ключевым разделам

### Secondary (Вторичная)

**Назначение:** Второстепенные действия, альтернативные варианты.

**Визуальные характеристики:**
- **Фон:** `bg-bg-secondary` (#F4F4F4)
- **Граница:** `2px solid` с прозрачностью `primary-500/30`
- **Текст:** Белый (`text-white`)
- **Hover:**
  - Граница: `primary-500` (полная непрозрачность)
  - Текст: `primary-100`
- **Скругление:** `rounded-lg` (8px)
- **Тень:** Отсутствует

**Использование:**
- Альтернативные действия
- Дополнительные опции
- Вторичные CTA

### Outline (Контурная)

**Назначение:** Третичные действия, отмена, нейтральные действия.

**Визуальные характеристики:**
- **Фон:** Прозрачный (`bg-transparent`)
- **Граница:** `2px solid primary-500`
- **Текст:** `primary-500`
- **Hover:**
  - Граница: `primary-400`
  - Текст: `primary-400`
- **Скругление:** `rounded-lg` (8px)
- **Тень:** Отсутствует

**Использование:**
- Отмена действий
- Нейтральные действия
- Дополнительные опции без акцента

### Yellow (Желтая)

**Назначение:** Акцентные действия, привлечение внимания.

**Визуальные характеристики:**
- **Фон:** Градиент `from-accent to-accent` (#F2AE3E)
- **Текст:** Белый (`text-white`)
- **Тень:** 
  - По умолчанию: `shadow-lg`
  - При hover: `shadow-xl`
- **Hover:**
  - Текст: `accent/90` (90% прозрачности)
  - Тень увеличивается
- **Скругление:** `rounded-lg` (8px)
- **Граница:** Отсутствует

**Использование:**
- Специальные предложения
- Промо-акции
- Важные уведомления

### Green Dark (Темно-зеленая)

**Назначение:** Премиум-действия, важные подтверждения.

**Визуальные характеристики:**
- **Фон:** Градиент `from-primary-700 to-primary-800` (#2E6F51 → #245a45)
- **Текст:** Белый (`text-white`)
- **Тень:**
  - По умолчанию: `shadow-lg`
  - При hover: `shadow-xl`
- **Hover:**
  - Текст: `primary-200`
  - Тень увеличивается
- **Скругление:** `rounded-lg` (8px)
- **Граница:** Отсутствует

**Использование:**
- Премиум-функции
- Важные подтверждения
- Высокоприоритетные действия

## Размеры

### Extra Small (xs)

**Характеристики:**
- **Padding:** `px-3 py-1.5` (12px горизонтально, 6px вертикально)
- **Размер текста:** `text-sm` (14px)
- **Высота:** Автоматическая
- **Тень:** Отсутствует

**Использование:**
- Компактные интерфейсы
- Внутри карточек
- Вторичные действия в ограниченном пространстве

### Small (sm)

**Характеристики:**
- **Padding:** `px-3 py-1.5` (12px горизонтально, 6px вертикально)
- **Размер текста:** `text-sm` (14px)
- **Высота:** Автоматическая
- **Тень:** Отсутствует

**Использование:**
- Компактные формы
- Вспомогательные действия
- Мобильные интерфейсы

### Medium (md) - По умолчанию

**Характеристики:**
- **Padding:** 
  - Мобильные: `px-4 py-2.5` (16px × 10px)
  - Десктоп: `px-6 py-3` (24px × 12px)
- **Размер текста:** `16px` (для primary)
- **Font weight:** `600` (semibold)
- **Высота (primary):** `52px` (фиксированная)
- **Тень (primary):** Присутствует

**Использование:**
- Основные действия на странице
- Формы
- Навигация

### Large (lg)

**Характеристики:**
- **Padding:**
  - Мобильные: `px-6 py-3` (24px × 12px)
  - Десктоп: `px-8 py-4` (32px × 16px)
- **Размер текста:** `text-lg` (18px)
- **Font weight:** `600` (semibold)
- **Высота (primary):** `52px` (фиксированная)
- **Тень (primary):** Присутствует

**Использование:**
- Главные CTA на странице
- Важные действия
- Лендинги

## Состояния

### Default (По умолчанию)

- Кнопка в обычном состоянии
- Все визуальные характеристики соответствуют варианту

### Hover

**Общие правила:**
- Плавный переход: `transition-all duration-200` (200ms)
- Изменение цвета текста/границы согласно варианту
- Увеличение тени для вариантов с тенью (primary, yellow, green-dark)
- Курсор: `pointer`

**Специфичные изменения:**
- **Primary:** Текст → `primary-100`, тень увеличивается
- **Secondary:** Граница → `primary-500`, текст → `primary-100`
- **Outline:** Граница → `primary-400`, текст → `primary-400`
- **Yellow:** Текст → `accent/90`, тень → `shadow-xl`
- **Green Dark:** Текст → `primary-200`, тень → `shadow-xl`

### Active (Нажатие)

- Легкое затемнение фона (если применимо)
- Небольшое уменьшение масштаба (опционально)
- Сохранение hover-эффектов

### Disabled (Отключена)

**Визуальные характеристики:**
- **Opacity:** `0.5` (50% прозрачности)
- **Курсор:** `not-allowed`
- **Transform:** Отключен (`transform-none`)
- Все hover-эффекты отключены
- Тени остаются, но с пониженной непрозрачностью

**Поведение:**
- Кнопка не реагирует на клики
- Hover-эффекты не применяются
- Визуально четко показывает недоступность

### Loading (Загрузка)

**Визуальные характеристики:**
- Используется компонент `LoadingButton`
- Отображается спиннер вместо текста
- Кнопка автоматически становится disabled
- Задержка показа: `200ms`
- Минимальное время отображения: `1000ms`

**Поведение:**
- Предотвращает двойные клики
- Автоматически управляет состоянием disabled
- Плавное появление/исчезновение спиннера

## Полная ширина (fullWidth)

**Характеристики:**
- Кнопка занимает 100% ширины контейнера
- Применяется класс `w-full`
- Используется для мобильных интерфейсов и форм

**Использование:**
- Мобильные формы
- Модальные окна
- Полноширинные CTA

## Типографика

### Шрифт

- **Font family:** Системный шрифт (наследуется)
- **Font weight:** `600` (semibold) для всех вариантов
- **Text align:** `center`
- **Letter spacing:** Стандартный

### Размеры текста

- **xs/sm:** `14px` (text-sm)
- **md:** `16px` (для primary), стандартный для остальных
- **lg:** `18px` (text-lg)

## Скругления и границы

### Скругление

- **Все варианты:** `rounded-lg` (8px)
- Единообразно для всех размеров

### Границы

- **Primary, Yellow, Green Dark:** Без границы
- **Secondary:** `2px solid` с цветом `primary-500/30`
- **Outline:** `2px solid` с цветом `primary-500`

## Тени

### Варианты с тенью

**Primary (md/lg):**
- Default: `0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)`
- Hover: `0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 10px 10px -5px rgba(0, 0, 0, 0.04)`

**Yellow:**
- Default: `shadow-lg`
- Hover: `shadow-xl`

**Green Dark:**
- Default: `shadow-lg`
- Hover: `shadow-xl`

### Варианты без тени

- **Secondary:** Без тени
- **Outline:** Без тени
- **Primary (xs/sm):** Без тени

## Анимации и переходы

### Transition

- **Свойство:** `transition-all`
- **Длительность:** `duration-200` (200ms)
- **Timing function:** По умолчанию (ease)

### Анимируемые свойства

- Цвет текста
- Цвет фона
- Цвет границы
- Тень (для вариантов с тенью)
- Opacity (для disabled)

## Интерактивность

### Курсор

- **Default/Hover:** `pointer`
- **Disabled:** `not-allowed`

### Select

- **User select:** `select-none` (текст не выделяется)

### Focus

- Стандартный браузерный focus (можно улучшить для accessibility)
- Рекомендуется добавить видимый focus ring для клавиатурной навигации

## Адаптивность

### Responsive padding

- **md:** `px-4 md:px-6 py-2.5 md:py-3`
- **lg:** `px-6 md:px-8 py-3 md:py-4`

### Мобильные устройства

- Увеличенные области касания (минимум 44×44px)
- Полная ширина для форм на мобильных
- Адаптивные размеры текста

- `primary-100`: #d4ede4 (hover текст для primary)
- `primary-200`: #a9dbc9 (hover текст для green-dark)
- `primary-300`: #75C9A5
- `primary-400`: #5fa88a (hover для outline)
- `primary-500`: #40916B (основной цвет)
- `primary-600`: #40916B
- `primary-700`: #2E6F51 (green-dark градиент)
- `primary-800`: #245a45 (green-dark градиент)

- `accent`: #F2AE3E (yellow вариант)

## Примеры использования

### Форма входа

```tsx
<Button variant="primary" size="md" fullWidth type="submit">
  Войти
</Button>
```

### Вторичное действие

```tsx
<Button variant="secondary" size="md">
  Отмена
</Button>
```

### Нейтральное действие

```tsx
<Button variant="outline" size="sm">
  Подробнее
</Button>
```

### Загрузка

```tsx
<LoadingButton
  loading={isSubmitting}
  loadingText="Сохранение..."
  variant="primary"
  size="md"
>
  Сохранить
</LoadingButton>
```

## Доступность (Accessibility)

### Требования

- Все кнопки должны иметь доступный текст или `aria-label`
- Disabled кнопки должны иметь `aria-disabled="true"`
- Loading кнопки должны иметь `aria-busy="true"` во время загрузки
- Focus должен быть видимым для клавиатурной навигации
- Контрастность текста и фона должна соответствовать WCAG 2.1 AA (минимум 4.5:1)

### Рекомендации

- Добавить focus ring для всех кнопок
- Использовать семантические HTML элементы (`<button>` вместо `<div>`)
- Обеспечить достаточный размер области касания (минимум 44×44px)

## Технические детали

### Компонент

- **Файл:** `core/frontend/ui/Button.tsx`
- **Типы:** TypeScript с полной типизацией
- **Зависимости:** React, Tailwind CSS

### Стилизация

- Используется Tailwind CSS
- Инлайн стили для primary варианта (тень и высота)
- Остальные стили через классы Tailwind

### Производительность

- Плавные анимации (200ms)
- Оптимизированные transition
- Минимальные перерисовки

## Чеклист для разработчиков

При создании или изменении кнопок убедитесь:

- [ ] Выбран правильный вариант (primary/secondary/outline/yellow/green-dark)
- [ ] Выбран правильный размер (xs/sm/md/lg)
- [ ] Состояния (hover/active/disabled) работают корректно
- [ ] Анимации плавные (200ms)
- [ ] Disabled состояние визуально различимо
- [ ] На мобильных устройствах кнопка достаточно большая для касания
- [ ] Контрастность соответствует WCAG 2.1 AA
- [ ] Focus видим для клавиатурной навигации
- [ ] Используется правильный компонент (`Button` или `LoadingButton`)
- [ ] Для загрузки используется `LoadingButton` с правильными параметрами
