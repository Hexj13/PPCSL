# Sitemap (Backend)

## Overview

The sitemap is generated by the **backend** (NestJS) from the database and served as XML. The frontend proxies requests to the backend via Next.js route handlers (`app/sitemap.xml/route.ts`, `app/sitemap.txt/route.ts`, `app/sitemaps/[name]/route.ts`).

**Sitemap index URL:** `https://kupito.club/sitemap.xml` (use without trailing slash in GSC)  
**Format:** XML (`Content-Type: application/xml; charset=utf-8`), UTF-8 encoding. Each XML file must start with the prolog `<?xml version="1.0" encoding="UTF-8"?>`.  
**Cache:** 1 hour (Redis + `Cache-Control: public, max-age=3600, s-maxage=3600`)

## Architecture

```text
GET /sitemap.xml          → Next.js route handler → GET /api/sitemap.xml (backend)
GET /sitemap.txt          → Next.js route handler → GET /api/sitemap.txt (backend)
GET /sitemaps/:name.xml   → Next.js route handler → GET /api/sitemaps/:name (backend)
```

- **Backend** (`core/backend/src/sitemap/`): `SitemapModule`, `SitemapController`, `SitemapService`
- **Frontend** (`core/frontend/app/`): route handlers for `/sitemap.xml`, `/sitemap.txt`, `/sitemaps/[name]`; they proxy to the backend with retries and return 502 with a body on upstream failure.
- **robots.txt** (`core/frontend/app/robots.ts`): `Sitemap: https://kupito.club/sitemap.xml` and `Sitemap: https://kupito.club/sitemap.txt`

## Sitemap Index and Child Sitemaps

| URL                              | Content                                                    | Priority | changefreq    |
| -------------------------------- | ---------------------------------------------------------- | -------- | ------------- |
| `/sitemap.xml`                   | Sitemap index (`pages`, `brands-{car\|truck\|moto}`, `tires`, `sellers`, `listings-*` — **no nested sitemap index**, per Google) | —        | —             |
| `/sitemap.txt`                   | Plain-text sitemap mirror for crawlers and diagnostics (includes both default-locale and `/ru` URLs derived from each `<loc>`) | —        | —             |
| `/sitemaps/tires.xml`           | Tire category and tire taxonomy URLs                       | 0.7–0.8  | daily         |
| `/sitemaps/pages.xml`            | Static pages                                               | 0.2–1.0  | daily/monthly |
| `/sitemaps/brands-car.xml`      | Brand + brand+model URLs for passenger cars (`car`)       | 0.7–0.8  | daily         |
| `/sitemaps/brands-truck.xml`    | Same for commercial (`truck`)                             | 0.7–0.8  | daily         |
| `/sitemaps/brands-moto.xml`     | Same for motorcycles (`moto`)                             | 0.7–0.8  | daily         |
| `/sitemaps/sellers.xml`          | Seller board pages (active sellers with ≥1 active listing) | 0.6      | daily         |
| `/sitemaps/listings-YYYY-MM.xml` | Active listings created in that month                      | 0.9      | hourly        |

Only **Active** listings are included. Seller boards are included only if the user is active, has a `board_slug`, and has at least one Active listing.

The path **`/sitemaps/brands.xml`** is **not** served (404). Older setups must rely on the root index only; do not submit a nested sitemap index in GSC.

**Crawl policy:** `robots.txt` must **not** disallow `/board/` if seller board URLs are listed here. Board pages use indexable metadata (`robots` index/follow) so sitemap entries match crawl eligibility.

## What's Included

| Type                 | Included | File                 | Notes                                                              |
| -------------------- | -------- | -------------------- | ------------------------------------------------------------------ |
| Static pages         | Yes      | pages.xml            | `/`, `/listings`, `/terms`, `/privacy`, `/faq`, `/partners`, `/contacts`, `/cookie-settings` (`/investors` is excluded; see next row) |
| Investor page        | No       | —                    | `/investors` is a normal route but **omitted** from `pages.xml`; `app/investors/layout.tsx` sets `robots` to **noindex, nofollow** so it is not meant for organic search. |
| Brand pages          | Yes      | brands-*.xml         | Split by `vehicleType`: `car` / `truck` / `moto` (see below)        |
| Brand+Model pages    | Yes      | brands-*.xml         | Bucket from first model `vehicle_types` entry, else `car`          |
| Seller boards        | Yes      | sellers.xml          | `/board/:board_slug` — only active sellers with active listings    |
| Individual listings  | Yes      | listings-YYYY-MM.xml | `/listings/:id` — Active only, partitioned by month; closed listings are excluded from sitemap and additionally marked `noindex` on their detail pages |
| Body type pages      | No       | —                    | Removed; use brand/model and search for discovery                  |
| Auth, profile, admin | No       | —                    | Excluded by design                                                 |

## URL Structure

Each indexable URL is emitted **once** per child sitemap as a `<url>` entry. The Romanian (default) canonical URL is in `<loc>`. The Russian locale is referenced with `<xhtml:link rel="alternate" hreflang="ru" href="..."/>` (plus `hreflang="ro"` and `hreflang="x-default"` pointing at the same URL as `<loc>`). Child urlsets declare `xmlns:xhtml="http://www.w3.org/1999/xhtml"` on `<urlset>`.

### Static Pages (pages.xml)

| URL                | Priority | changefreq |
| ------------------ | -------- | ---------- |
| `/`                | 1.0      | daily      |
| `/listings`        | 0.9      | daily      |
| `/terms`           | 0.3      | monthly    |
| `/privacy`         | 0.3      | monthly    |
| `/faq`             | 0.4      | monthly    |
| `/partners`        | 0.4      | monthly    |
| `/contacts`        | 0.3      | monthly    |
| `/cookie-settings` | 0.2      | monthly    |

`/investors` is intentionally **not** in this urlset (same omission in `sitemap.txt` extraction).

### Brand and Model URLs (`brands-car.xml`, `brands-truck.xml`, `brands-moto.xml`)

- The root **`/sitemap.xml`** lists these three **urlset** files directly (not via an intermediate `brands.xml` sitemap index).
- **Brand rows:** each entry in `brand.vehicle_types` goes to the matching bucket. Car URLs use `/{brand}`; truck and moto URLs use `/{brand}?vehicleType=truck|moto`.
- **Model rows:** first value in `model.vehicle_types` selects the bucket. Car URLs use `/{brand}/{model}`; truck and moto URLs use `/{brand}/{model}?vehicleType=truck|moto`.

Brand and model path segments are slugified without diacritics. All `<loc>` values are escaped in XML (`&` → `&amp;`).

### Seller Boards (sellers.xml)

- URL: `https://kupito.club/board/{board_slug}` — same path is allowed for crawling in `robots.txt`; page is indexable.
- `lastmod`: max `updated_at` among the seller's Active listings

### Listings (listings-YYYY-MM.xml)

- URL: `https://kupito.club/listings/{id}` in `<loc>`; Russian listing URL in `hreflang="ru"` alternate (same path under `/ru/...`).
- Partitioned by `created_at` month to keep each file under 50,000 URLs (one `<url>` per listing, not doubled by locale).
- `lastmod`: listing `updated_at`

## Backend Implementation

### Files

| File                                             | Description                                                          |
| ------------------------------------------------ | -------------------------------------------------------------------- |
| `core/backend/src/sitemap/sitemap.module.ts`     | NestJS module (TypeORM entities, CommonModule)                       |
| `core/backend/src/sitemap/sitemap.controller.ts` | `GET /api/sitemap.xml`, `GET /api/sitemaps/:name`; `@SkipThrottle()` |
| `core/backend/src/sitemap/sitemap.service.ts`    | XML generation, DB queries, Redis cache (TTL 3600s)                  |

### Caching

- Key prefix: `sitemap:v3:` (Redis; bump when sitemap XML shape changes to avoid stale cached XML)
- Keys: `sitemap:v3:index`, `sitemap:v3:pages`, `sitemap:v3:brands-car`, `sitemap:v3:brands-truck`, `sitemap:v3:brands-moto`, `sitemap:v3:sellers`, `sitemap:v3:listings-YYYY-MM`, `sitemap:v3:tires`, `sitemap:v3:txt`
- TTL: 3600 seconds (1 hour)

### Database Queries

- **Listings by month:** Active listings with `created_at` in the given month, ordered by `updated_at` DESC, `id` ASC.
- **Sellers:** Distinct `board_slug` from users joined with listings where `user.active = true`, `board_slug IS NOT NULL`, and listing `status = 'Active'`; `lastmod` = max listing `updated_at` per seller.
- **Brands/Models:** From `Brand` and `VehicleModel` entities (alphabetical).

## XML format requirements

- Prolog: `<?xml version="1.0" encoding="UTF-8"?>` at the start of every XML sitemap (index and child files).
- Encoding: UTF-8.
- Child **urlsets** include `xmlns:xhtml="http://www.w3.org/1999/xhtml"` and, for bilingual URLs, three self-closing elements: `<xhtml:link rel="alternate" hreflang="ro" href="..."/>`, `<xhtml:link rel="alternate" hreflang="ru" href="..."/>`, `<xhtml:link rel="alternate" hreflang="x-default" href="..."/>` (see [Google: localized versions](https://developers.google.com/search/docs/specialized/international/localized-versions#sitemap)).
- URL escaping in `<loc>` and in `href` attributes: `&` → `&amp;`, `<` → `&lt;`, etc. (handled in `SitemapService.escapeXml()`).
- Limits per file: up to 50,000 URLs and 50 MB uncompressed (listings are split by month to stay under the limit).

## Fallback (if frontend proxy fails in production)

If the frontend proxy does not work (e.g. GSC still cannot fetch the sitemap):

1. In `core/frontend/app/robots.ts`, expose the public sitemap endpoints (`https://kupito.club/sitemap.xml` and `https://kupito.club/sitemap.txt`).
2. In Google Search Console, submit `https://kupito.club/sitemap.xml`.

Google allows the sitemap to be on a different subdomain; URLs inside the sitemap must point to the verified property (e.g. `https://kupito.club/...`).

For diagnosing Google Search Console sitemap errors and re-submission steps, see [operations/](../operations/) runbooks or SEO audit docs.
