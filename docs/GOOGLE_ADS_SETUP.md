## Архитектура отслеживания

### Текущая реализация

Проект использует **рекомендуемый подход**:

1. **Google Analytics 4 (GA4)** - отслеживает все пользовательские события
2. **Google Ads конверсии** - импортируются из GA4 (единственный рекомендованный способ)

### Поток данных

```
Пользователь → Сайт → GA4 (все события) → Google Ads (только конверсии)
```

## Настройка Google Analytics 4

### Шаг 1: Создание события в GA4

1. Перейдите в [Google Analytics](https://analytics.google.com/)
2. Выберите свой ресурс (property) "Kupito Website"
3. Перейдите: **Администратор** → **События** → **Создать событие**

### Шаг 2: Настройка событий как конверсий

Для каждого важного события:

1. Перейдите: **Администратор** → **События**
2. Найдите нужное событие (например, `sign_up`, `create_listing`)
3. Включите переключатель **"Отметить как конверсию"**

### Основные события для конверсий в GA4

Проект использует **3 основные конверсии**:

| Событие GA4 | Когда отправляется | Приоритет |
|------------|-------------------|-----------|
| `conversion_event_page_view` | Просмотр главной страницы | Высокий |
| `sign_up` | Успешная регистрация нового пользователя | Высокий |
| `create_listing` | Успешное создание нового объявления | Высокий |

## Настройка конверсий в Google Ads

### Импорт из Google Analytics 4

Этот метод автоматически синхронизирует конверсии из GA4 в Google Ads и является единственным рекомендованным способом настройки конверсий.

#### Шаг 1: Связывание аккаунтов

1. В Google Ads: **Инструменты и настройки** → **Настройки** → **Связанные аккаунты**
2. Найдите **Google Analytics (GA4)**
3. Нажмите **"Связать"** и выберите свой ресурс GA4
4. Включите **"Импорт конверсий из Google Analytics"**

#### Шаг 2: Импорт конверсий

1. Перейдите: **Цели** → **Конверсии**
2. Нажмите **"+"** → **Импорт**
3. Выберите **"Google Analytics (GA4)"**
4. Выберите события, которые нужно импортировать:
   - ✅ `conversion_event_page_view` (Просмотр главной страницы)
   - ✅ `sign_up` (Успешная регистрация нового пользователя)
   - ✅ `create_listing` (Успешное создание нового объявления)

#### Шаг 3: Настройка каждой конверсии

Для каждой импортированной конверсии:

1. Откройте конверсию: **Цели** → **Конверсии** → [Название конверсии]
2. Настройте параметры:

   **Для `conversion_event_page_view` (Просмотр главной страницы):**
   - **Категория:** Просмотры страниц
   - **Оптимизация:** Просмотры страниц, Главное действие
   - **Ценность:** Использовать значение по умолчанию (1 €)
   - **Учет:** Каждая конверсия
   - **Окно конверсии:** 1 день (для кликов), 1 день (для просмотров)
   - **Атрибуция:** На основе данных (Рекомендуется)

   **Для `sign_up` (Успешная регистрация нового пользователя):**
   - **Категория:** Регистрация
   - **Оптимизация:** Регистрации, Главное действие
   - **Ценность:** Использовать сумму из GA4 (если есть) или значение по умолчанию
   - **Учет:** Каждая конверсия
   - **Окно конверсии:** 30 дней (для кликов), 3 дня (для просмотров)
   - **Атрибуция:** На основе данных (Рекомендуется)

   **Для `create_listing` (Успешное создание нового объявления):**
   - **Категория:** Регистрация
   - **Оптимизация:** Регистрации, Главное действие
   - **Ценность:** Использовать сумму из GA4 (цена объявления)
   - **Учет:** Каждая конверсия
   - **Окно конверсии:** 90 дней (для кликов), 3 дня (для просмотров)
   - **Атрибуция:** На основе данных (Рекомендуется)

**Важно:** Все события должны быть сначала настроены в GA4 и отмечены как конверсии, а затем импортированы в Google Ads. Не настраивайте события напрямую в Google Ads - это может привести к дублированию данных.

## Связывание GA4 с Google Ads

### Автоматическая синхронизация

После связывания аккаунтов:

1. **Автоматический импорт:** Конверсии из GA4 автоматически появляются в Google Ads
2. **Обновление данных:** Данные обновляются каждые 3-24 часа
3. **Атрибуция:** Google Ads использует модель атрибуции "На основе данных"

### Настройка атрибуции

1. Перейдите: **Цели** → **Конверсии** → [Конверсия] → **Настройки**
2. Выберите модель атрибуции:
   - **На основе данных (Рекомендуется)** - использует машинное обучение
   - **Последний клик** - простая модель
   - **Первое взаимодействие** - для верхней воронки

## Основные конверсии

Проект использует **3 основные конверсии** для отслеживания эффективности рекламы:

### 1. Просмотр главной страницы (`conversion_event_page_view`)

- **Цель:** Отслеживание визитов на сайт
- **Когда отправляется:** При загрузке главной страницы
- **Оптимизация:** Просмотры страниц, Главное действие
- **Окно конверсии:** 1 день
- **Приоритет:** Высокий - показывает общий интерес к сайту

### 2. Успешная регистрация нового пользователя (`sign_up`)

- **Цель:** Привлечение новых пользователей на платформу
- **Когда отправляется:** После успешной регистрации пользователя
- **Оптимизация:** Регистрации, Главное действие
- **Окно конверсии:** 30 дней
- **Приоритет:** Высокий - ключевая метрика для роста аудитории

### 3. Успешное создание нового объявления (`create_listing`)

- **Цель:** Получение контента на платформу
- **Когда отправляется:** После успешного создания объявления
- **Оптимизация:** Регистрации, Главное действие
- **Окно конверсии:** 90 дней (дольше, т.к. пользователь может вернуться позже)
- **Приоритет:** Высокий - ключевая метрика для качества платформы

## Проверка работы

### Шаг 1: Проверка в Google Analytics

1. Перейдите: **Отчеты** → **События в реальном времени**
2. Выполните действие на сайте (например, регистрацию)
3. Убедитесь, что событие появляется в реальном времени

### Шаг 2: Проверка в Google Ads

1. Перейдите: **Цели** → **Конверсии**
2. Найдите вашу конверсию
3. Проверьте столбец **"Статус"**:
   - ✅ **"Записывается"** - конверсия работает
   - ⚠️ **"Нет недавних конверсий"** - подождите 24-48 часов для первых данных
   - ❌ **"Не записывается"** - проверьте настройки

### Шаг 3: Тестирование с Google Tag Assistant

1. Установите расширение [Google Tag Assistant](https://tagassistant.google.com/)
2. Откройте сайт и выполните действие
3. Проверьте, что события отправляются корректно

### Шаг 4: Проверка в режиме реального времени

1. В Google Ads: **Цели** → **Конверсии** → [Конверсия] → **Подробности**
2. Выберите период: **"Последние 30 дней"**
3. Выполните тестовое действие на сайте
4. Подождите 15-30 минут и проверьте, появилась ли конверсия

## Оптимизация кампаний

### Использование конверсий для оптимизации

1. **Установка целей кампании:**
   - Перейдите: **Кампании** → [Кампания] → **Настройки**
   - Выберите **"Цель"** → выберите основную конверсию:
     - `sign_up` - для кампаний по привлечению пользователей
     - `create_listing` - для кампаний по привлечению продавцов
     - `conversion_event_page_view` - для кампаний по увеличению трафика

2. **Автоматические ставки:**
   - **Целевая цена за конверсию (CPA):** Для фиксированного бюджета
   - **Максимальная цена за конверсию:** Для контроля затрат
   - **Целевая рентабельность инвестиций (ROAS):** Если есть ценность конверсий

3. **Умные ставки:**
   - Используйте **"Умные ставки"** для автоматической оптимизации
   - Требуется минимум 15-30 конверсий за последние 30 дней

### Настройка групп объявлений

1. **Приоритет конверсий:**
   - Перейдите: **Группы объявлений** → [Группа] → **Настройки**
   - Выберите **"Оптимизация"** → основная конверсия
   - Установите **"Приоритет конверсий"** для нескольких конверсий

2. **Исключения аудитории:**
   - Создайте сегменты для уже зарегистрированных пользователей
   - Исключите их из кампаний по регистрации

## Частые проблемы и решения

### Проблема 1: Конверсии не записываются

**Причины:**
- События не отправляются из кода
- Неправильное имя события в GA4/Google Ads
- Пользователь не дал согласие на аналитику

**Решение:**
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что событие отправляется через `gtag('event', ...)`
3. Проверьте, что пользователь дал согласие на cookies

### Проблема 2: Задержка данных

**Причина:** Данные из GA4 обновляются в Google Ads с задержкой 3-24 часа

**Решение:** Это нормально, подождите до 24 часов для первых данных

### Проблема 3: Дублирование конверсий

**Причина:** Одно и то же событие настроено и в GA4, и напрямую в Google Ads

**Решение:** Используйте только импорт из GA4. Не настраивайте события напрямую в Google Ads - это приведет к дублированию данных

### Проблема 4: Неправильная атрибуция

**Причина:** Неправильная модель атрибуции или окно конверсии

**Решение:**
1. Используйте модель "На основе данных"
2. Установите правильное окно конверсии (30-90 дней для регистраций)
