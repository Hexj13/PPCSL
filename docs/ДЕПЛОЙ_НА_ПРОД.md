# 🚀 Деплой Kupito на продакшн (kupito.mk)

Краткая инструкция для деплоя на хостинг mkhost.com с cPanel.

## 📋 Что нужно сделать

### 1️⃣ Войти в cPanel

- Откройте: **https://luna.mk-host.mk/cpanel** или **https://kupito.mk/cpanel**
- Войдите используя данные из письма от хостинга

### 2️⃣ Создать базу данных

1. В cPanel найдите **"MySQL Databases"** (или PostgreSQL, если доступен)
2. Создайте базу данных: `kupito`
3. Создайте пользователя с надежным паролем
4. **ВАЖНО:** Запишите полные имена (с префиксом `kupitomk_`):
   - База: `kupitomk_kupito`
   - Пользователь: `kupitomk_user`
   - Пароль: (ваш пароль)

### 3️⃣ Включить SSH доступ и загрузить проект

**Шаг 1: Включить SSH в cPanel**

1. Войдите в cPanel: https://luna.mk-host.mk/cpanel
2. Найдите раздел **"SSH Access"** (обычно в секции "Security" или "Advanced")
3. Если SSH отключен, нажмите **"Enable SSH Access"** или **"Manage SSH Access"**
4. Следуйте инструкциям для активации SSH

**Шаг 2: Настроить SSH ключ**

1. В cPanel → **"SSH Access"** → **"Manage SSH Keys"**
2. Убедитесь, что ваш публичный ключ добавлен и авторизован
3. Если ключа нет, добавьте публичный ключ с вашего Mac:
   ```bash
   cat ~/.ssh/kupito_key.pub
   ```
   Скопируйте вывод и добавьте в cPanel через "Import Key"

**Шаг 3: Подключиться через SSH**

```bash
ssh -i ~/.ssh/kupito_key kupitomk@luna.mk-host.mk
```

**Шаг 4: Клонировать проект**

После успешного подключения:

```bash
cd ~/public_html
git clone https://github.com/ваш-username/kupito.git
cd kupito
```

### 4️⃣ Настроить переменные окружения

**Создайте файл `backend/.env`:**

```env
NODE_ENV=production
PORT=4000
DB_HOST=localhost
DB_USERNAME=kupitomk_user
DB_PASSWORD=ваш_пароль_из_шага_2
DB_NAME=kupitomk_kupito
JWT_SECRET=сгенерируйте_надежный_ключ_32_символа
FRONTEND_URL=https://kupito.mk
```

**Сгенерировать JWT_SECRET:**
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

**Создайте файл `frontend/.env.local`:**
```env
NEXT_PUBLIC_API_URL=https://kupito.mk/api
NEXT_PUBLIC_SITE_URL=https://kupito.mk
```

### 5️⃣ Собрать проект

```bash
# Backend
cd backend
npm install --production
npm run build
npm run migration:run

# Frontend
cd ../frontend
npm install --production
npm run build
```

### 6️⃣ Настроить Node.js приложения в cPanel

1. В cPanel найдите **"Node.js"** или **"Setup Node.js App"**
2. Создайте приложение для **Backend**:
   - **Node.js version:** 20.x или выше
   - **Application root:** `/home/kupitomk/public_html/kupito/backend`
   - **Application URL:** `/api`
   - **Startup file:** `dist/main.js`
3. Создайте приложение для **Frontend**:
   - **Application root:** `/home/kupitomk/public_html/kupito/frontend`
   - **Application URL:** `/`
   - **Startup file:** `node_modules/next/dist/bin/next`
   - **Arguments:** `start`

### 7️⃣ Установить SSL сертификат

1. В cPanel найдите **"SSL/TLS Status"**
2. Нажмите **"Run AutoSSL"**
3. Подождите несколько минут

### 8️⃣ Проверить работу

- Frontend: https://kupito.mk
- Backend API: https://kupito.mk/api
- Health check: https://kupito.mk/api/health

## ⚠️ Важные моменты

1. **База данных:** Используйте PostgreSQL, если доступен (не MySQL)
2. **Пароли:** Генерируйте надежные пароли для базы данных и JWT_SECRET
3. **Префиксы:** Не забывайте про префиксы в именах базы данных и пользователя
4. **Бэкапы:** Настройте автоматические бэкапы через cPanel → Backup
5. **Логи:** Проверяйте логи в cPanel → Node.js → View Logs

## 🆘 Если что-то не работает

1. Проверьте логи в cPanel → Node.js → View Logs
2. Убедитесь, что все файлы собраны (`npm run build`)
3. Проверьте переменные окружения
4. Убедитесь, что база данных создана и пользователь имеет права
5. Проверьте, что SSL сертификат установлен
