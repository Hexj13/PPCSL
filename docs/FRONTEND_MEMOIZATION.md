# Frontend Memoization - Оптимизация производительности

## Обзор

Добавлена мемоизация для ключевых компонентов frontend для улучшения производительности и уменьшения ненужных ререндеров.

## Реализованные оптимизации

### 1. ListingCard ✅

**Проблема**: Компонент рендерится много раз в списках объявлений, что может вызывать лаги при скролле.

**Решение**:
- Обернут в `React.memo` с кастомной функцией сравнения
- Мемоизированы вычисления: `imageUrl`, `isFavorite`, `isOwnListing`
- `handleToggleFavorite` обернут в `useCallback`

**Результат**: Компонент ререндерится только при изменении ключевых свойств listing.

### 2. MultiSelectDropdown ✅

**Проблема**: Компонент используется в SearchFilters и может ререндериться при каждом изменении фильтров.

**Решение**:
- Обернут в `React.memo`
- Мемоизированы: `selectedOptions`, `displayText`, `filteredOptions`
- Обработчики событий обернуты в `useCallback`

**Результат**: Компонент не ререндерится, если props не изменились.

### 3. Dropdown ✅

**Проблема**: Аналогично MultiSelectDropdown, используется в SearchFilters.

**Решение**:
- Обернут в `React.memo`
- Мемоизированы: `selectedOption`, `displayText`, `filteredOptions`
- Обработчики событий обернуты в `useCallback`

**Результат**: Улучшена производительность фильтров поиска.

### 4. UserListingsModal ✅

**Проблема**: Модальное окно может ререндериться при изменении родительских компонентов.

**Решение**:
- Обернут в `React.memo`
- Мемоизированы: `getUserDisplayName`, `displayListings`
- Уже использовался `useMemo` для `targetUserId`

**Результат**: Модальное окно не ререндерится без необходимости.

## Технические детали

### React.memo

Используется для предотвращения ререндеров компонентов, если props не изменились:

```typescript
export const Component = React.memo(ComponentFunction);
```

### Кастомная функция сравнения

Для `ListingCard` используется кастомная функция сравнения для более точного контроля:

```typescript
export const ListingCard = React.memo(ListingCardComponent, (prevProps, nextProps) => {
  return (
    prevProps.listing.id === nextProps.listing.id &&
    prevProps.listing.title === nextProps.listing.title &&
    // ... другие важные поля
  );
});
```

**Важно**: Функция возвращает `true`, если props равны (не нужно ререндерить), и `false` если нужно ререндерить.

### useMemo

Используется для мемоизации вычислений:

```typescript
const expensiveValue = useMemo(() => {
  return computeExpensiveValue(a, b);
}, [a, b]);
```

### useCallback

Используется для мемоизации функций:

```typescript
const handleClick = useCallback(() => {
  doSomething(a, b);
}, [a, b]);
```

## Best Practices

### Когда использовать React.memo

✅ **Используйте**, когда:
- Компонент рендерится часто с теми же props
- Компонент тяжелый (много вычислений)
- Компонент используется в списках

❌ **Не используйте**, когда:
- Компонент всегда получает новые props
- Компонент очень простой (overhead больше выгоды)
- Props часто меняются

### Когда использовать useMemo

✅ **Используйте**, когда:
- Вычисление дорогое (фильтрация больших массивов, сложные вычисления)
- Значение используется в зависимостях других hooks
- Значение передается как prop в мемоизированный компонент

❌ **Не используйте**, когда:
- Вычисление очень простое
- Значение всегда новое (нет смысла кэшировать)

### Когда использовать useCallback

✅ **Используйте**, когда:
- Функция передается как prop в мемоизированный компонент
- Функция используется в зависимостях других hooks
- Функция создается в цикле

❌ **Не используйте**, когда:
- Функция всегда новая (нет смысла кэшировать)
- Функция очень простая

## Troubleshooting

### Проблема: Компонент все еще ререндерится

**Причины**:
- Props меняются каждый раз (новые объекты/массивы)
- Функции создаются заново каждый раз
- Родительский компонент ререндерится

**Решение**:
- Использовать `useMemo` для объектов/массивов
- Использовать `useCallback` для функций
- Мемоизировать родительский компонент

### Проблема: Компонент не обновляется

**Причина**: Кастомная функция сравнения слишком строгая

**Решение**: Проверить логику сравнения в `React.memo`
