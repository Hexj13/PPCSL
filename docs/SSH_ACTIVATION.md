# Активация SSH доступа

## Текущая ситуация

✅ **Ключ `kupito_key` добавлен и авторизован** в cPanel  
❌ **SSH подключение не работает** (порт 22 недоступен)

## Проблема

Авторизация ключа ≠ активация SSH доступа. Нужно отдельно включить SSH.

## Решение: Активировать SSH доступ

### Вариант 1: Через cPanel (если доступно)

1. В cPanel найдите раздел **"SSH Access"**
2. Ищите кнопки или ссылки:
   - **"Enable SSH Access"**
   - **"Request SSH Access"**
   - **"Manage SSH Access"**
   - **"SSH Access Settings"**

3. Если есть настройки, проверьте:
   - SSH должен быть **"Enabled"** или **"Active"**
   - Может быть переключатель **"Allow SSH Access"**

### Вариант 2: Через поддержку хостинга

Если в cPanel нет опции активации SSH:

1. **Обратитесь в поддержку mkhost.com:**
   - https://mkhost.com/en/other/contact
   - https://portal.mkhost.com/help-desk/open-ticket

2. **Запросите:**
   - "Пожалуйста, активируйте SSH доступ для аккаунта kupitomk"
   - "Нужен SSH для деплоя Node.js приложения"
   - Укажите домен: kupito.mk

3. **Обычно активация занимает:**
   - Несколько минут (автоматическая)
   - До 24 часов (ручная проверка)

### Вариант 3: Проверить тип тарифа

Некоторые shared hosting тарифы не включают SSH:

1. Проверьте ваш тариф в cPanel или панели управления
2. Если SSH не включен в тарифе, может потребоваться:
   - Обновление тарифа
   - Переход на VPS/выделенный сервер

## После активации SSH

Когда SSH будет активирован, попробуйте подключиться:

```bash
ssh -i ~/.ssh/kupito_key kupitomk@luna.mk-host.mk
```

Или с настройкой из config:

```bash
ssh kupito
```

## Альтернативные порты (если основной не работает)

Некоторые хостинги используют нестандартные порты:

```bash
# Попробуйте порт 2222
ssh -i ~/.ssh/kupito_key -p 2222 kupitomk@luna.mk-host.mk

# Или порт 2200
ssh -i ~/.ssh/kupito_key -p 2200 kupitomk@luna.mk-host.mk
```

## Что делать сейчас

1. **Проверьте в cPanel** раздел "SSH Access" на наличие кнопки активации
2. **Если нет** - обратитесь в поддержку mkhost.com
3. **Пока ждете** - можете подготовить проект локально (настроить .env файлы)
